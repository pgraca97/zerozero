# zerozero

A browser brick-breaker game built with React, Phaser 4, TypeScript and Vite. Originally written in p5.js.

🎮 **[Play it here](https://pgraca97.github.io/zerozero/)**

> This is **v1**, frozen as a static GitHub Pages build. Development continues in **[zerozero-v2](https://github.com/pgraca97/zerozero-v2)**, which adds a backend, a monorepo and cloud deploys. You can [play v2 here](https://zerozero-v2.paulodcgraca.workers.dev).
